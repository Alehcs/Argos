First test build of Argos 1.1.

- Argos's own name and logo everywhere: the program, the window, the tray and the installer.
- Two modes on the Quality page: Normal, the best quality (1440p at 60 fps, the last 5 minutes), and Performance, lighter while you play (1080p at 60 fps, the last minute). Everything below them can still be changed.
- When the game loses frames, the Status page says so and offers the Performance mode. Nothing pops up while you play.
- The tray icon tells the state: the mark in color while Argos keeps the last minutes, in grey when it does not, and a dot for recording, saved, error and paused.
- Lighter while you play: the background part does its memory clean-ups in one go instead of alongside the game, and Smart Save's voice models keep less memory to themselves.
- "Open post" only opens the site's own secure page.
